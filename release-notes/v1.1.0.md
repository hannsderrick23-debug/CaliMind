## What's new

- Replaced circular loading indicators with an animated star loader throughout
  the app.
- Added a notification center for upcoming task reminders and recent push
  notifications, with read and clear controls.
- Persisted incoming pushes by signed-in account, including background and
  cold-start delivery events.
- Prepared Android notification channels for reliable task reminder display.

## Setup notes

- Closed-app cloud reminders require the Supabase push function, migrations,
  secrets, and scheduled dispatcher configured as described in the
  [push notification setup guide](https://github.com/hannsderrick23-debug/CaliMind/blob/v1.1.0/supabase/PUSH_NOTIFICATIONS.md).
- The Android release workflow requires the `ANDROID_GOOGLE_SERVICES_JSON`
  GitHub Actions secret to build the APK.
