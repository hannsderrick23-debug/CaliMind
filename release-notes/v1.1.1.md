## Setup notes

- Closed-app cloud reminders require the Supabase push function, migrations,
  secrets, and scheduled dispatcher configured as described in the
  [push notification setup guide](https://github.com/hannsderrick23-debug/CaliMind/blob/v1.1.1/supabase/PUSH_NOTIFICATIONS.md).
- The Android release workflow requires the `ANDROID_GOOGLE_SERVICES_JSON`
  GitHub Actions secret to build the APK.
