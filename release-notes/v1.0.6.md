## What's new

- Task reminders now default to 30 minutes before an exact start time. Adjust
  the reminder or turn it off while creating a task or confirming a voice task.
- Optional cloud push delivery supports task reminders and schedule-ready
  notifications, while local reminders remain available on the device.
- Task and schedule requests are scoped to the signed-in account. Aventor Eye
  refreshes use authenticated account data and keep cached insights separate
  per account.
- Deleting a task now asks for confirmation, and network failures show a clear
  message with guidance to check the connection.

## Setup notes

- Cloud push delivery requires the Supabase function, migrations, secrets, and
  scheduled dispatcher described in the [push notification setup guide](https://github.com/hannsderrick23-debug/CaliMind/blob/v1.0.6/supabase/PUSH_NOTIFICATIONS.md).
- The Android release workflow requires the `ANDROID_GOOGLE_SERVICES_JSON`
  GitHub Actions secret to build the APK.
